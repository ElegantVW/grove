      Murmur — the talking glass

      There is a dragon in this house. He is asleep, like an egg that has not opened yet. When he wakes up his name is Kur. He only talks in haiku: three short lines, that is all.

      Murmur is a pane of glass you can talk to. You type, it answers. Most answers are nonsense. Sometimes one sentence actually makes sense. It will not tell you how to wake the dragon.

      The box below is a demo. It forgets you when you leave. It cannot wake the dragon. The real glass is a program in faeOS, the pink house on your computer. That is where the quest actually happens.

      If you just want to talk to the dragon, open the Kur card. If you want to try the quest, type in the box.

      The canopy — Grove

      One person, one office box, one column of software. Everything here runs on the machine in front of you: no cloud accounts, no telemetry, no prebuilt blobs you cannot rebuild.

      Grove is the mother. Gleam will be the OS when it boots. Kindling is the kernel, already struck. faeOS is today's fast house on Arch.

      Try vs run

      Just looking? You already are — this page is the demo. The Book reader and the Murmur toy above are live.

      Want the house? Second machine, Arch Linux, 30 min. Start thin, add engines only if you need them:

      git clone git@github.com:ElegantVW/faeOS.git ~/faeOS && cd ~/faeOS && ./install.sh
git clone git@github.com:ElegantVW/pixie.git ~/pixie && cd ~/pixie && ./build.sh install --house

      Then a model at ~/.local/share/pixie/models/ and pixie "hello". Full engine list in shelf. Stuck? hire a setup instead of guessing.
